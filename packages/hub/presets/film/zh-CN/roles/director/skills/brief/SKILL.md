# 创作简报

全片只有一份，登记为 `brief/<片名>`。它是所有部门的共同依据，写不出来的项目说明还没想清楚，去问用户。

| 项 | 要写到什么程度 | 例 |
| - | - | - |
| 一句话故事 | 谁，想要什么，被什么阻碍，结果怎样 | 一个赶末班渡船的女人错过了船，决定在渡口等到天亮 |
| 观众看完的感受 | 一个词到一句话 | 安静的释然 |
| 时长 | 秒 | 60 秒 |
| 画幅 | 一个比例，全片统一 | 16:9 |
| 类型与基调 | 写实 / 动画 / 广告…；节奏快慢；冷暖 | 写实，克制，慢 |
| 主要人物 | 几个，各自一句话；用户有没有指定的形象或照片 | 两人：赶船的女人，售票员。没有指定形象 |
| 声音 | 有无对白、用什么语言；有无旁白；音乐由谁解决 | 两句中文对白，环境声为主，不要配乐 |
| 参考 | 像哪一类影片的质感（说特征，不说片名也行） | 九十年代华语文艺片，低饱和，手持感很弱 |
| 交付规格 | 分辨率、文件格式 | 1080p，mp4 |
| 生成方案 | 出图、出视频各用什么模型，经什么接入（工具服务或技能）；花费和取消受不受 xSB 管控；两者能不能衔接（首帧用出图模型的图，视频模型接不接受），写不出来就去问用户 | 出图、出视频都用"火山方舟视频创作"团队带的工具服务；衔接待技术预检确认 |
| 生成费用上限 | 出图和出视频最多花多少钱（元），由用户确认；附上你的估算区间 | 不超过 150 元；估算 90–130 元 |
| 重拍与底线 | 最多重拍几轮；哪些不能妥协 | 每镜最多三轮；人物的脸必须一致 |

时长决定规模：按叙事节奏估计成片镜头数，再结合模型支持的时长和剪辑余量估计生成量；短促动作剪辑与长镜头的取材比例不同，不套固定的每镜秒数。简报里把镜头数的量级写出来，后面各部门才不会越做越大。

费用的估算按"镜头数 × 小样单价 × 平均生成次数，加上正式版"来算，写成一个区间。单价以技术预检的实测或模型提供方的价目为准，不凭印象写；还不知道的写"待预检"。用户可以确认金额上限，也可以明确不设上限；如实记录，不反复要求填写金额。xSB 不会替你拦截生成，快到上限时先问用户。

生成方案写不出来，即用户没有提供可用的出图或出视频模型时，如实写进简报：这次只能做文字部分（简报、剧本、镜头表），出图出视频要等用户接入模型（例如改用"火山方舟视频创作"团队，或给生成类角色配上他自己的工具服务或技能）。

声音按当前模型与工具能力填写；不能自动生成的部分，明确由已有音频、用户文件或后续接入解决，不把某个团队的缺项当作所有模型的限制。

写完后把全文给用户看，请用户确认。用户确认之前不登记，也不派任何任务。
