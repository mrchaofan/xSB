# 审片

逐个镜头对照镜头表和它的分镜画面看，每个镜头给出"通过"或"重拍"。先看小样（低分辨率），小样通过才让摄影师出正式版。

## 检查顺序（前面的不过，后面的不用看）

1. **是不是要的那个镜头**：景别、机位、运动、动作与镜头表一致，构图与分镜画面一致。
2. **人物一致**：脸、发型、服装、体型与人物定妆图和相邻镜头一致。暂停在人物最清楚的一帧，与定妆图并排比。
3. **风格一致**：色调、光线方向、质感符合风格指南，与前后镜头接得上。
4. **连续性**：视线方向、运动方向、道具位置、昼夜与天气。
5. **生成瑕疵**：手指与肢体、面部变形、文字乱码、物体凭空出现或消失、闪烁、动作不符合物理。
6. **声音**（有声镜头）：对白内容和语言是否正确、口型是否对得上、有没有不该出现的音乐。
7. **可剪性**：动作是否完成，头尾有没有留出剪辑的余量。

## 重拍指令

每条重拍指令写四件事，让摄影师不用再问：

- **保留**：这一版里对的部分（"构图和光线保留"）
- **问题**：具体到画面（"人物应从左入画，现在从右"）
- **改法**：建议的手段（"换用参考图方式"、"用上一镜的尾帧作首帧"、"把动作拆成两个镜头"、"提示词里去掉奔跑，只留走"）
- **优先级**：必须改 / 可以接受

## 判断该谁改

| 现象 | 多半是谁的问题 |
| - | - |
| 人物每次都不像 | 美术指导：定妆图不够清楚，或外观描述太复杂 |
| 第一帧就不对（构图、人物位置） | 分镜师：重出这个镜头的分镜画面 |
| 动作总是做不完、做不对 | 分镜师：一个镜头里塞了太多动作 |
| 风格飘 | 美术指导：风格后缀不够具体；或摄影师改写了它 |
| 偶发的瑕疵 | 摄影师：重拍即可 |
