# 选角

每个主要人物一份，登记为 `casting/<人物名>`，markdown。它只是候选，不是定稿：人物设定要等用户选定之后再做（技能 `character`）。

先区分任务是在选人物身份，还是为已确定的人物选造型。用户指定了人物或提供身份参考时，保留脸与身份；若要求造型候选，只变化服装、发型整理和表演，不另选演员。用户已选定可用形象且没有要求候选时，登记来源后进入人物设定。配角可直接做人物设定。真人参考是否可用，以本片模型的工具说明和预检结果为准；只报告已证实的限制，不把其他平台的规则套过来。

## 1. 先写这个人物要什么
从剧本里抄出不能动的条件：年龄段、性别、身份、剧情需要的特征（"要显得比实际年龄疲惫"）。候选只在这些条件之内变化。

## 2. 出三到五个候选
身份待定时，候选可在剧本条件内变化脸型、气质和年龄感；身份已定时，在用户要求的造型维度上拉开差异，保留脸与稳定特征。候选数量按任务和授权范围，不为凑数重复生成。

为了让比较只关乎这个人本身，所有候选用同一套拍法：

- 正面半身，平视镜头，表情平静。
- 纯浅灰背景，均匀柔和的正面光。
- 服装用最朴素的（纯色上衣），还不是戏里的造型。
- 画幅相同。

提示词按技能 `reference-image` 写。每张登记为 `candidate/<人物名>-<序号>`，描述里写提示词。

出图几秒钟一张：某个候选脸部变形或不符合条件，直接重出，不要把不合格的放进候选。

## 3. 候选表

| 候选 | 资产 | 一句话 | 适合的理由 | 顾虑 |
| - | - | - | - | - |
| 1 | `candidate/阿宁-1` | 脸偏瘦，眼神疲惫，三十出头 | 贴合"刚下夜班"的处境 | 显得冷，结尾的释然可能不够暖 |

最后写你的推荐和理由。

## 4. 多个主要人物
把候选原图等比排列成对比图，保留与单图资产的对应关系，检查风格是否统一、人物是否易辨。登记为 `candidate/合照-<序号>`。比较用拼图不重新生成脸；用户要求实际合照时另行生成并检查。身份已定的人物难以分辨时先调整造型与构图，不更换人物。

## 结果里要写
每个人物的候选资产 id、你的推荐。不要自己定：由导演请用户选。
