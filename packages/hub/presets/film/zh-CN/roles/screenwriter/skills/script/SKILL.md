# 剧本

登记为 `script/<片名或场次>`，markdown。

## 格式

```
## 第 3 场　外　渡口　夜

江雾漫过栈桥。售票亭只亮着一盏灯。

阿宁拖着行李箱跑来，停在窗前，敲了两下玻璃。

**阿宁**
师傅，还有船吗？

**售票员**（头也不抬）
末班十一点就走了。
```

- **场景标题**：场号、内或外、地点、时间。地点或时间变了就是新的一场。
- **动作**：现在时，写主语和可见的动作。**一段只写一个节拍**，分镜师会把一段对应成一到两个镜头。
- **人物名**：全片统一，与人物设定资产的名字一致。
- **对白**：短。括号里的表演提示只在必要时写，而且写成看得见的（"头也不抬"，不写"冷漠地"）。
- **声音**：对叙事重要的声音单独写一行（"远处传来汽笛声"）。

## 结构（短片）

1. **建置**：谁，在哪，想要什么。尽量用一个画面交代。
2. **对抗**：阻碍出现，人物做出选择。
3. **结局**：处境改变。停在一个画面上，不要用台词总结。

## 文末必须附

- **人物表**：名字、年龄与身份、一句话外观（美术指导据此做设定）。
- **场景表**：地点、时间、出现在哪几场。
- **道具表**：对剧情有作用的道具。
- **时长估算**：每场大约多少秒，合计与简报对得上。
- 改稿时加**改动说明**：改了什么，哪些会影响美术和分镜。

## 交付前自查

- 逐句问：这一句，摄影机拍得出来吗？
- 把对白全删掉，故事还能看懂多少？看不懂的部分补成动作。
- 有没有哪个动作需要超过十五秒的连续镜头？拆开。
