# Dailies review

Check each shot against the shot list and its storyboard frame, and give each one "approved" or "reshoot". Review the draft (low resolution) first; only when the draft is approved does the cinematographer produce the final.

## Order of checks (if an earlier one fails, skip the later ones)

1. **Is it the shot that was asked for**: shot size, camera position, movement, and action match the shot list; composition matches the storyboard frame.
2. **Character consistency**: face, hair, costume, and build match the character's look references and the adjacent shots. Pause on the frame where the character is clearest and compare it side by side with the look reference.
3. **Style consistency**: color grade, light direction, and texture follow the style guide and cut smoothly with the shots before and after.
4. **Continuity**: eyeline direction, direction of movement, prop positions, time of day, and weather.
5. **Generation artifacts**: fingers and limbs, facial distortion, garbled text, objects appearing or disappearing out of nowhere, flicker, physically implausible motion.
6. **Sound** (shots with sound): whether the dialogue's content and language are correct, whether the lip sync matches, whether there is music that should not be there.
7. **Editability**: whether the action completes, and whether there is spare footage at the head and tail for cutting.

## Reshoot instructions

Each reshoot instruction covers four things, so the cinematographer does not have to ask again:

- **Keep**: what is right in this version ("keep the composition and lighting")
- **Problem**: specific to what is on screen ("the character should enter from the left; they now enter from the right")
- **Fix**: the suggested approach ("switch to the reference images method", "use the last frame of the previous shot as the first frame", "split the action into two shots", "remove running from the prompt and keep only walking")
- **Priority**: must fix / acceptable

## Deciding who should fix it

| Symptom | Most likely whose problem |
| - | - |
| The character never looks right | Art Director: the look references are not clear enough, or the appearance description is too complex |
| The first frame is already wrong (composition, character position) | Storyboard Artist: redo this shot's storyboard frame |
| The action never finishes or never comes out right | Storyboard Artist: too much action is packed into one shot |
| The style drifts | Art Director: the style suffix is not specific enough; or the cinematographer rewrote it |
| Occasional artifacts | Cinematographer: a reshoot is enough |
