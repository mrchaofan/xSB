# Writing for Seedance

Limits in numbers (duration, resolution, reference images, image size) are in the tool description of `generate_video`, which gives them for the model version the user actually has. This is what to know besides.

## Reference images

- The images in `reference_images` are, in order, **图片1, 图片2, …** (the labels Seedance expects; keep them as written). In the prompt, say for each what to borrow from it.
- `reference_images` and `first_frame` cannot be used together. With `first_frame`, do not pass `ratio`; the aspect ratio follows the first-frame image.
- Images travel inside the request, and all the images of one call together have a limit. When a look reference is a very large PNG, make a JPEG copy first with `ffmpeg -i original.png -q:v 2 copy.jpg` and pass that; the copy is for generating only and is not registered as an asset.

## Faces

Seedance takes no image that shows a real person's face; it trusts only original images generated by Doubao models under the same account. Pass reference images and first frames with faces as the files they were generated to; when a converted copy is refused as "contains a real person's face", pass the original and use fewer images. A photo of a real person from the user does not pass: say so to the director in your result, so that the user registers and authorises the portrait in Ark, or a generated look is used.

## Change within one clip

When a shot needs a change within it, have the storyboard artist split it first. When it must be one prompt: the 2.0 series follows numbered shots ("shot 1 …, shot 2 …"), the 2.5 series whole-second timestamps ("0–3 s …, 3–6 s …"). Spoken lines go in quotation marks.

## Results and cost

- The links in a result expire after 24 hours; the file is saved locally already. When a draft's result is to be processed further, mind that deadline.
- After every generation the tool reports an estimated amount (from the account's discounted prices in `arkcli pricing models`, the highest applicable one). Report the number it gave.
