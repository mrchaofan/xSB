# 人物设定

每个人物一份，登记为 `character/<人物名>`，名字与剧本一致。

主要人物的脸已经在选角时由用户选定：任务里会写明用哪一张候选（`candidate/<人物名>-<序号>`）。**那张图就是这个人**，后面每一张图都以它为参考，不要重新设计脸。没有经过选角的配角，从第 4 节的正面半身开始做。

## 1. 基本信息
年龄、身份、在故事里的作用（一句话）。

## 2. 外观
- **脸与发型**：照选中的候选写，脸型、肤色、发型发色，最稳定的一两个特征。
- **体型与姿态**：身高体型、站姿和走路的方式。
- **服装**：每套的款式、颜色、材质，出现在哪些场。颜色选与场景有区分度的。
- **标志物**：一件随身的东西，帮助识别。

避免容易生成出错的设计：复杂花纹、文字图案、细碎的首饰、镜面反光的材质。

## 3. 外观描述（必写）
**一段 30–60 字的固定文字**，在这个人物出现的每个镜头里原样使用。只写看得见的特征，顺序固定：年龄性别 → 脸与发型 → 服装 → 标志物。

> 三十岁的女性，齐肩黑发，脸型偏瘦，穿深灰色长风衣和白色衬衫，背一只褪色的墨绿帆布包。

换服装时新增一段，注明适用的场次。

## 4. 定妆图（必做）

定妆是把选中的那张脸穿上戏里的造型。按技能 `reference-image` 出图，每张都把选中的候选作为参考图传入，并写明"保持图一的脸完全一致"。画风（写实、动画、质感）按 `style_guide` 第 1 节和第 5 节，背景和光线仍用干净平光。每张登记为 `reference/<人物名>-<视角>`：

| 图 | 用途 |
| - | - |
| 正面半身 | 脸与造型的基准，最重要的一张 |
| 全身 | 服装与体型 |
| 侧面或四分之三侧 | 戏份重的人物才需要 |
| 表情（两到三种剧本里用得到的） | 有近景表演的人物才需要 |

顺序很重要：**先把正面半身做到满意**，再把它作为参考图去出其余几张，这样才是同一个人。每出一张都与选中的候选并排比一次脸。

换装的人物，每套服装出一张正面半身，登记为 `reference/<人物名>-<服装名>`。

在设定表里列出每张定妆图的资产 id 和用途。分镜师和摄影师按这张表取图。

## 5. 表演范围
常见的表情和动作习惯；这个人物不会做的事。
