# 选角

每个主要人物一份，登记为 `casting/<人物名>`，markdown。它只是候选，不是定稿：人物设定要等用户选定之后再做（技能 `character`）。

只为主要人物选角。配角、只出现一两个镜头的人物直接做人物设定。用户在简报里指定了形象或给了照片的人物，不出候选，把用户给的那张登记为唯一候选并说明来源。

## 1. 先写这个人物要什么
从剧本里抄出不能动的条件：年龄段、性别、身份、剧情需要的特征（"要显得比实际年龄疲惫"）。候选只在这些条件之内变化。

## 2. 出三到五个候选
候选之间要**拉得开**：脸型、气质、年龄感各不相同，让选择有意义。不要给同一张脸的三种微调。

为了让比较只关乎这个人本身，所有候选用同一套拍法：

- 正面半身，平视镜头，表情平静。
- 纯浅灰背景，均匀柔和的正面光。
- 服装用最朴素的（纯色上衣），还不是戏里的造型。
- 画幅相同。

提示词按技能 `reference-image` 写。每张登记为 `candidate/<人物名>-<序号>`，描述里写提示词。

出图几秒钟一张：某个候选脸部变形或不符合条件，直接重出，不要把不合格的放进候选。

## 3. 候选表

| 候选 | 资产 | 一句话 | 适合的理由 | 顾虑 |
| - | - | - | - | - |
| 1 | `candidate/阿宁-1` | 脸偏瘦，眼神疲惫，三十出头 | 贴合"刚下夜班"的处境 | 显得冷，结尾的释然可能不够暖 |

最后写你的推荐和理由。

## 4. 多个主要人物
把你各自推荐的候选并排出一张合照式的对比图（同一背景、同一光线），看他们站在一起是否像同一部片子里的人、彼此是否分得清。登记为 `candidate/合照-<序号>`。两个人长得太像，换掉其中一个。

## 结果里要写
每个人物的候选资产 id、你的推荐。不要自己定：由导演请用户选。
