# 分镜画面

镜头表经导演通过后才做。每个镜头一张静帧，画的是**这个镜头的第一帧**。它有三个用处：导演在生成视频之前看到构图；剪辑师把它们排成动态分镜看节奏；摄影师把它作为首帧去生成视频。

登记一份总表 `storyboard/<片名或场次>`（markdown），每张画面登记为 `frame/<镜号>`。

## 出图

用 `media` 的 `generate_image`，每个镜头一次：

- `reference_images`：出场人物的定妆图（从 `character` 的设定表里取），加这场戏的场景参考图（从 `style_guide` 里取）。提示词里按顺序称它们为图一、图二，并说清各借用什么。
- 提示词顺序：人物的外观描述（从 `character` **原样复制**）→ 这一帧里人物的位置和姿态 → 场景 → 景别与机位 → 光线 → 风格后缀（从 `style_guide` **原样复制**）。
- 画幅用简报的画幅，全片统一。视频会跟随这张图的画幅。
- 写的是动作**开始那一刻**的画面，不是动作完成的样子。"从左侧走到窗前"的第一帧是人物在画面左侧。

例：

> 参考图一的人物，保持脸、发型和服装完全一致：三十岁的女性，齐肩黑发，脸型偏瘦，穿深灰色长风衣和白色衬衫，背一只褪色的墨绿帆布包。她站在画面左侧边缘，拖着行李箱，身体朝向画面右侧的售票亭。场景参考图二：深夜的渡口，江面有雾，售票亭亮着一盏昏黄的灯。中景，平视。唯一的光源来自售票亭。写实电影质感，低调布光，钨丝灯暖光与青色阴影，浅景深，胶片颗粒，色彩克制，画面无文字。16:9 横构图。

## 各种生成方式要画什么

| 镜头表写的 | 画什么 |
| - | - |
| 首帧 | 第一帧，登记为 `frame/<镜号>` |
| 首尾帧 | 第一帧和最后一帧，后者登记为 `frame/<镜号>-尾`；出尾帧时把首帧也作为参考图，保证是同一个空间 |
| 接尾帧 | 仍然画一张，只用于审看和动态分镜；视频会用上一镜的尾帧 |
| 参考图、文生 | 画一张有代表性的画面，只用于审看和动态分镜 |

## 检查（每张）

- 人物与定妆图并排比：脸、发型、服装一致吗？
- 景别、机位与镜头表一致吗？
- 与上一镜的画面放在一起：轴线、视线方向、光线方向接得上吗？
- 手和脸有没有变形，有没有多出来的文字或物体？

不合格就改提示词重出，一次只改一处。

| - | - | - | - | - |
