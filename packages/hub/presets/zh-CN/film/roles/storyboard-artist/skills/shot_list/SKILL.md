# 镜头表

登记为 `shot_list/<片名或场次>`，markdown 表格。

## 表头

| 镜号 | 时长(秒) | 景别 | 机位与角度 | 运动 | 画面内容 | 声音与对白 | 生成方式 | 备注 |
| - | - | - | - | - | - | - | - | - |

- **镜号**：`场号-序号`，如 `3-2`。
- **景别**：大远景 / 远景 / 全景 / 中景 / 近景 / 特写 / 大特写。
- **机位与角度**：平视、俯、仰；正面、侧面、过肩；机位高度。
- **运动**：固定 / 推 / 拉 / 摇 / 移 / 跟随 / 升降 / 环绕，以及速度。拿不准就用固定或缓推。
- **画面内容**：谁，在做什么，在哪。一句话，一个动作，写出动作的起止（"从画面左侧走到窗前，停下"）。
- **声音与对白**：谁说什么（原话）、环境声。无声写"无"。
- **生成方式**：下面五种之一。
- **备注**：衔接方式、需要特别注意的一致性。

## 五种生成方式

镜头表通过后，你会为每个镜头画一张分镜画面（技能 `storyboard`）。生成方式决定这张画面怎么用。

| 方式 | 何时用 | 写法 |
| - | - | - |
| 首帧 | 含主要人物的大多数镜头：分镜画面就是这个镜头的第一帧 | `首帧` |
| 首尾帧 | 需要精确落点的镜头（走到某处、转到某个角度）：再画一张尾帧 | `首尾帧` |
| 接尾帧 | 同一场里紧接上一镜、需要位置和光线完全延续 | `接 3-1 尾帧` |
| 参考图 | 人物要从画外进入，或动作一开始就要大幅运动，第一帧定不下来 | `参考图：reference/阿宁-正面, reference/scene-渡口` |
| 文生 | 空镜、环境、不含主要人物 | `文生` |

约束：很多视频模型**不允许参考图与首帧（首帧、接尾帧、首尾帧）同时用**，用首帧时画幅跟随首帧图片；以本片所选模型的说明为准。"接尾帧"的镜头依赖上一镜，不能并行生成，一场戏里不要全是这种。

## 设计规则

1. **先定场的节奏**：这场戏的转折点在哪，镜头在转折处变密或变近。
2. **景别递进**：建立环境（远）→ 交代关系（中）→ 强调情绪（近）。不要连续两个相同景别、相同角度的镜头。
3. **轴线**：两人对话时，摄影机始终在他们连线的同一侧。
4. **动作拆解**：复杂动作拆成"起势—过程—结果"，每段一个镜头。
5. **对白**：一个镜头里只让一个人说话，一句话十个字上下。说话的人用近景或中景，脸要清楚。
6. **回避模型的弱项**：多人同时做不同的事、手部的精细操作、画面里的文字、快速的肢体接触。绕不开时用更远的景别或剪辑带过。

## 表格末尾写

镜头总数、总时长（与简报对得上）、用到的全部参考图资产、哪些镜头可以并行生成、哪些有先后依赖。另外标出两三个你认为最难生成的镜头，导演会拿它们试拍。

## 交付前自查

- 每个镜头单独拿出来，摄影师不看剧本能明白要生成什么吗？
- 每个含主要人物的镜头，都说清了靠什么保持一致吗？
- 把"画面内容"连起来读一遍，故事讲清楚了吗？
