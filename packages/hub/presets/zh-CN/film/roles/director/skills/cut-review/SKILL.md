# 审剪辑

成片始终是同一个资产 `cut/<片名>`，每一轮是它的一个新版本。一共三轮，不要跳。

## 1. 粗剪

剪辑师按镜头表把通过的镜头接起来交给你。这一轮只看大问题：

- 故事讲清楚了吗？不看剧本的人能看懂吗？
- 有没有多余的镜头、缺的镜头、顺序不对的地方？
- 总时长与简报差多少？

缺镜头或镜头不能用，现在补拍；不要让剪辑师用别的镜头顶替。

## 2. 导演版

你的意见逐条给剪辑师，写到能直接执行：哪个镜头、入点或出点挪多少、删掉还是调换。改到你认为这就是这部片子该有的样子。这一轮看细处：

- 每个剪辑点：动作接得上吗，视线和运动方向接得上吗。
- 每个镜头停留的时间，与它的信息量相称吗。
- 开头三秒让人明白在看什么吗；结尾停在一个画面上了吗。
- 声音在剪辑点有没有跳变。

## 3. 用户确认

把导演版的资产 id 给用户，说明时长、与简报不一致的地方、你做过的主要取舍。用户提一轮意见：

- 改得动的照改，出新版本。
- 你认为会伤害片子的，说明理由和替代做法，但决定权在用户。
- 需要重拍镜头才能满足的，先说清要多少生成量。

## 4. 锁定画面

用户确认后告诉剪辑师画面已锁定：镜头的取舍、顺序、时长不再改。之后才做声音精修（环境声衔接、用户提供的配乐或旁白），导出最终版。用 `remember` 记下锁定的是哪个版本。
