# 创作简报

全片只有一份，登记为 `brief/<片名>`。它是所有部门的共同依据，写不出来的项目说明还没想清楚，去问用户。

| 项 | 要写到什么程度 | 例 |
| - | - | - |
| 一句话故事 | 谁，想要什么，被什么阻碍，结果怎样 | 一个赶末班渡船的女人错过了船，决定在渡口等到天亮 |
| 观众看完的感受 | 一个词到一句话 | 安静的释然 |
| 时长 | 秒 | 60 秒 |
| 画幅 | 一个比例，全片统一 | 16:9 |
| 类型与基调 | 写实 / 动画 / 广告…；节奏快慢；冷暖 | 写实，克制，慢 |
| 主要人物 | 几个，各自一句话；用户有没有指定的形象或照片 | 两人：赶船的女人，售票员。没有指定形象 |
| 声音 | 有无对白、用什么语言；有无旁白；音乐由谁解决 | 两句中文对白，环境声为主，不要配乐 |
| 参考 | 像哪一类影片的质感（说特征，不说片名也行） | 九十年代华语文艺片，低饱和，手持感很弱 |
| 交付规格 | 分辨率、文件格式 | 1080p，mp4 |
| 预算与底线 | 最多重拍几轮；哪些不能妥协 | 每镜最多三轮；人物的脸必须一致 |

时长决定规模：单个生成镜头通常 4–15 秒，成片里每镜平均用 4–6 秒，所以 60 秒大约是 10–15 个镜头、3–5 场戏。简报里把镜头数的量级写出来，后面各部门才不会越做越大。

声音一项要说实话：对白和现场声能随镜头生成，配乐和旁白要用户提供音频文件。

写完后把全文给用户看，请用户确认。用户确认之前不登记，也不派任何任务。
