# 发布前核对

逐项确认，每一项都要有出处（资产 id 或命令输出），不能凭印象：

- [ ] `prd` 里"必须有"的需求，每一条都有对应的通过用例（见 `test_report`）
- [ ] `review` 结论为通过，没有未关闭的阻断项
- [ ] `test_report` 结论为可发布；已知缺陷都有处置（修复 / 接受并记录）
- [ ] 变更说明里的"未做与已知问题"已经告知用户
- [ ] 有数据或配置迁移时，有回滚办法
- [ ] 对外行为的变化已写进文档或更新日志

有任何一项不满足，结论就是"不能发布"，并写明缺的是哪一项。
