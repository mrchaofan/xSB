# 安全专项检查

变更涉及登录、权限、支付、文件上传、外部输入拼接、密钥时使用。

- **输入**：所有来自外部的数据（请求、文件、环境、第三方响应）在使用前是否校验了类型、长度、范围。
- **注入**：拼接进 SQL、shell 命令、文件路径、HTML、正则的地方，是否用了参数化或转义。
- **鉴权与越权**：每个入口是否检查了"是谁"和"能不能"；能否通过改 id 访问别人的数据。
- **密钥与敏感数据**：有没有写进代码、日志、错误信息、URL；传输和存储是否加密。
- **依赖**：新增的依赖是否必要、来源是否可信。
- **失败时**：出错是默认拒绝还是默认放行；错误信息是否泄露内部细节。

发现的问题按"阻断"写进评审。
