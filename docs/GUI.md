# 桌面工作区

左栏按工作区列出所有主会话。点击加号选择后端并新建会话。主区域只显示当前会话的对话和输入框，切换后保留草稿和历史。

主 Agent 保存候选或采用图后，右栏出现工作流标签。DAG 从上到下排列，连线标明依赖及分支选项。可在候选和活动版本间切换。点击 Markdown 节点能查看要求、入口给定的实参或直接前驱。派发后可查看本次实际输入、交付和已选下一节点，已启动的任务还可打开聊天。需要继续或重做时，在主对话说明意图。例如“保留行程，只重新生成短片”，主 Agent 会根据依赖关系选择回退范围。回退前的快照可在历史下拉菜单查看。

标题栏的“停止工作流”停止当前图的调度和节点工作，主对话可以继续。要单独停止任务，选中节点后点击“停止任务”。已派发节点的按钮在节点对话标题栏，待派发节点的按钮在节点详情中。其他独立节点继续运行，已有交付保留。

节点有待回答的问题或待处理的审批时，活动图会在该节点显示红点，主对话输入框上方会显示对应的提示卡片。点击卡片会打开右栏工作流面板，定位到节点对话中的那一项请求。请求处理或撤回后，卡片消失。该节点的最后一项请求关闭时，红点也随之消失。

工作区窗口未聚焦时，对话提问、审批请求和任务结束会触发系统通知。点击提问或审批通知可直接前往对应的请求。

拖动工作流图的下边缘可以调整图的高度，也可以折叠整张图，把空间让给下方的节点对话。选中节点时详情默认收起，点击「节点详情」即可展开。输入框上方列出当前图里可打开的智能体，点击即可切换。标题栏提供活动方案和候选方案切换，旁边的历史菜单可查看旧版图及节点对话。当前版本里已创建智能体的节点可以对话，被新版本删掉的节点和历史版本里的节点只显示记录。任务输入作用于节点当前的工作或交付，主对话里的消息在有工作流运行时也作用于该工作流。任务与主对话各自保存草稿。

右栏的「文件」列出当前主会话及其任务 Agent 通过 ACP v2 报告已成功创建、修改或保存的文件，也收录工作流节点在 Markdown 交付中链接的本地文件。移动更新路径，删除移出列表。聊天记录也显示对应的变更与路径。点击文件可预览并引用到输入框，聊天中的普通文件链接也可独立打开。正在预览的文件被 Agent 改写后会显示新内容，删除后会提示文件已不可用。切换主会话后恢复文件、网页标签、筛选和所选任务。

输入框下方可选择后端支持的模型和推理强度。设置属于该输入框对应的会话，首次打开选择器会连接后端获取选项。发送按钮旁的圆环显示后端上报的上下文用量，悬停可查看百分比及 token 数。虚线环表示用量尚未上报。[工作流指南](WORKFLOWS.md)

设置里的"插件"列出应用自带和这台设备的插件，"工作区插件"列出本工作区的插件，也可在本工作区单独停用任何插件。每个插件是一个文件夹，点"打开插件文件夹"放进去，再重启桌面端或点"重新加载"即可；无法使用的插件会写明原因，工作区里的插件要先确认才会启动。保存后空闲会话立即生效，工作中的会话在这一轮结束后生效，工具没有变化的会话不受影响。

工作区（.xsb2/config.json）的设置都可在设置里配置，与全局分类一一对应：“工作区偏好”里是智能体的工作语言；“工作区模型后端”里是上下文与执行的各项限制（续接阈值、提示预算、预留余量、单次工具输出、上下文恢复重试、同时运行的后台任务、工作流校验步数）；“工作区插件”里是本工作区的插件。每项显示默认值，留空即用默认，超出范围会提示；改动立即保存，下次用到时生效。

桌面端是单例应用，每个工作区的中枢由它启动并与它同生共死：中枢通过一根标准输入管道感知桌面端进程，桌面端退出、被强制结束或崩溃，管道关闭，中枢随之停止。打开工作区时如果已有一个不属于本应用的中枢在跑（之前的应用留下的，或命令行启动的），会先停掉它再启动自己的，保证界面连上的总是同一份代码。命令行 `xsb` 启动的中枢不受影响，仍然独立运行。
