# 向用户提问（ask）

`ask` 是 xSB 自己的工具，不属于工作流：任何对话的 Agent 都能用，有没有工作流都一样。它由名为 `xsb` 的 MCP 服务提供（代理程序里显示为 `mcp__xsb__ask` 或 `xsb.ask`），和 `workflow` 服务的工作流工具分开；两个服务是同一会话的两个桥，用同一个令牌，接入时声明自己是哪个服务。`ask` 的调用不写入工作流日志。

Agent 用 `ask` 问用户 1–4 个问题，每题是单选、多选或填空；单选和多选可以带 `other: true`，让用户另外填写。问题在对话里显示成一张卡片，Agent 显示"等你回答"。

`ask` 立即返回，Agent 随即结束这一轮。用户的回答就是他发给这个 Agent 的下一条消息，有三种：

- **提交**：模型收到每题的问题和答案，前面一句说明。
- **跳过**：模型收到"用户跳过"，自行决定并说明选了什么。
- **不回答、直接发消息**：问题结束，模型收到这条消息，前面说明用户没有回答。

工具调用不挂起等人：等待会超过代理程序的工具超时（codex 默认约 60 秒），也撑不过中枢重启；一条消息两者都不受影响。每个对话同时只有一个未答问题，新的提问替换旧的。

## 关键决策征询偏好

设置中的「AI 协作 → 关键决策征询」控制 AI 是否主动邀请用户参与复杂任务的重要决策。全局默认关闭；工作区提供「使用全局设置」「开启」「关闭」，显式工作区选择优先于全局设置。

开启后，内置征询技能要求 Agent 在目标与验收标准、差异显著的方案，以及范围、成本、时间或质量的取舍上征询意见。先查阅已有指令与材料，形成推荐方案和简短理由，再于大量实施之前提出少量、具体的问题；执行中出现新的重要取舍时继续征询。常规实现细节、已明确的选择和已授权步骤自主推进。关闭时优先自主判断，仅在用户明确要求或必需信息无法推断时询问。

此偏好同时适用于 ACP 原生表单与 xSB MCP ask，不关闭提问工具，也不代替操作审批或身份验证。任务 Agent 只征询自己职责内的问题，涉及整体计划或职责变化时按工作流规则升级给主会话。问题和选项采用对话语言；中英文界面与内置技能均提供本地化文案。

全局值存于 `~/.xsb2_global/config.json` 的 `consultUser` 布尔字段，工作区覆盖存于 `.xsb2/config.json` 的同名字段。工作区未设置该字段即继承；选择继承会删除覆盖字段。设置通过原子配置写入保存，全局值随设置备份导出与恢复。桌面端通知受影响的 Hub 使用既有提示词更新机制：空闲会话更新后端绑定，运行中的会话等工作结束后更新，保留历史与当前任务。

用户未回答不等于同意，依赖答案的工作须等待。跳过可选问题后可采用合理默认并说明；必需信息和授权仍须取得。ACP 原生请求仍在同一 turn 内等待回执，xSB ask 仍要求结束当前 turn 后通过下一条用户消息续接。

## 在工作流里

任务 Agent 在执行指派时提问：这一轮没调 `finish` 就结束，也不算未完成，工作保持进行、等待回答；回答所在的那一轮接续同一项工作，在其中 `finish`。回答若赶在提问那一轮结束前送到，会并入那一轮，那一轮仍须 `finish`。节点被暂停或中枢重启后，等待取消，之后的回答按普通插话处理。

## Claude 原生提问

保留上述自研工具，同时接入 Claude 的 `AskUserQuestion`：Hub 对 Claude 声明 `capabilities.elicitation.form: {}`，通过 `elicitation/create` 转交给支持表单的桌面客户端。Codex 不声明表单能力，继续使用自研 ask，避免 codex-acp 2.6.0 的异步问题在 turn 结束时失效。

两条路径复用同一个分页、数字键、单选/多选、其他答案及问答记录 UI。原生 schema 的字段名、枚举值与展示文字分别保存，Claude 的 `question_n_custom` 合并为对应问题的“其他”；可选字段可留空，默认值可修改后提交。Hub 验证回传内容，答案通过原 ACP 请求返回，跳过返回 `decline`，取消返回 `cancel`。

原生提问会等待回答并继续同一 turn，不要求模型提前结束。请求绑定 turn 和后端会话；提交用户答案时保护该 turn。停止、turn 结束、后端取消或断线使请求失效，迟到答案不转成下一条 prompt。原生记录标记 `source: "acp"`，重启时未完成请求标记取消；自研 ask 的消息式回复保持原有行为。新用户消息也可以取消原生表单，作为普通输入交给 Hub。

协议能力范围及版本差异见 [ACP 客户端能力](ACP-CLIENT-CAPABILITIES.md)。
